# bookmark-grid

## Purpose

以图标网格形式展示与管理常用站点书签，作为导航页的核心导航入口；用户可增删改书签并点击直达站点。

## ADDED Requirements

### Requirement: 书签网格展示
页面必须以网格形式展示已保存的书签，每个书签显示其名称与图标；点击书签必须在新标签页打开其目标网址。

#### Scenario: 展示已保存书签
- **WHEN** 用户已保存至少一个书签并打开页面
- **THEN** 网格中显示该书签的名称与图标

#### Scenario: 点击打开站点
- **WHEN** 用户点击某个书签
- **THEN** 浏览器在新标签页打开该书签的目标网址

#### Scenario: 空状态
- **WHEN** 用户没有任何书签
- **THEN** 网格区域显示引导用户添加书签的提示与入口

### Requirement: 添加书签
用户必须能够通过名称与网址添加新书签。输入的网址缺少协议时必须默认补全为 `https://` 后保存；空网址或格式无效的网址必须被拒绝并给出提示。

#### Scenario: 添加书签成功
- **WHEN** 用户填写名称"示例"与网址 `example.com` 并确认添加
- **THEN** 书签以网址 `https://example.com` 保存，并立即出现在网格中

#### Scenario: 拒绝无效网址
- **WHEN** 用户填写空网址或格式无效的网址并确认添加
- **THEN** 系统提示网址无效，书签不被添加

### Requirement: 编辑书签
用户必须能够修改已有书签的名称与网址；保存后网格必须立即反映修改。

#### Scenario: 修改书签
- **WHEN** 用户将某书签的名称与网址修改后保存
- **THEN** 网格中该书签显示新名称，点击时打开新网址

### Requirement: 删除书签
用户必须能够删除已有书签；删除后书签从网格移除且不再持久化。

#### Scenario: 删除书签
- **WHEN** 用户对某书签发起删除
- **THEN** 该书签从网格消失，刷新页面后也不再现

### Requirement: 图标回退
书签的站点图标获取失败时必须回退显示占位图标（如名称首字符），不得出现空白或破损图标。

#### Scenario: 图标获取失败
- **WHEN** 某书签的站点图标无法获取
- **THEN** 该书签显示占位图标
