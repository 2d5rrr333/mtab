# configuration Delta

## MODIFIED Requirements

### Requirement: 小组件开关
用户必须能够独立开启或关闭各小组件（时钟、书签网格、倒数日）的显示；开关状态立即生效并被持久保存。（假设：搜索框为导航页常驻基础组件，不提供开关。）

#### Scenario: 关闭时钟
- **WHEN** 用户关闭时钟开关
- **THEN** 时钟立即从页面消失，刷新后仍不显示

#### Scenario: 恢复显示
- **WHEN** 用户重新打开时钟开关
- **THEN** 时钟恢复显示，且相关数据与关闭前一致

#### Scenario: 倒数日开关
- **WHEN** 用户在设置面板切换倒数日开关
- **THEN** 倒数日小组件立即显示或隐藏，刷新后保持

### Requirement: 配置导出
用户必须能够将全部配置导出为单个 JSON 文件。文件必须包含格式版本字段，并涵盖书签、小组件开关、搜索引擎选择、壁纸设置与倒数日条目；自定义上传的壁纸必须以其图像数据内嵌，使导出文件可独立恢复完整配置。

#### Scenario: 导出产生文件
- **WHEN** 用户点击导出
- **THEN** 浏览器下载一个包含版本字段与全部配置的 JSON 文件
