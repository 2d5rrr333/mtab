# configuration Delta

## ADDED Requirements

### Requirement: 主题设置
用户必须能够在设置面板选择界面主题：深色、浅色或跟随系统；选择立即生效并持久保存，刷新后保持；"跟随系统"必须实时响应系统深浅色切换；非法主题值必须被拒绝且不影响当前主题。

#### Scenario: 切换浅色主题
- **WHEN** 用户点击"浅色"
- **THEN** 界面立即切换为浅色配色，刷新后仍为浅色

#### Scenario: 跟随系统
- **WHEN** 用户选择"跟随系统"且系统处于浅色模式
- **THEN** 界面呈浅色；系统切换为深色后无需刷新即呈深色

#### Scenario: 非法值拒绝
- **WHEN** 收到不在 {深色, 浅色, 跟随系统} 内的主题值
- **THEN** 提示错误，当前主题保持不变
