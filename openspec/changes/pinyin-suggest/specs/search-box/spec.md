# search-box Delta

## ADDED Requirements

### Requirement: 拼音联想
当用户输入为纯英文字母时，系统除原文前缀匹配外，必须同时基于历史条目的无声调全拼（ü 编码为 v）与首字母串进行前缀联想（忽略大小写）；命中条目按"原文前缀、全拼前缀、首字母前缀"的优先级排序，同级内沿用频次与时间综合排序。拼音表覆盖常用汉字；表外字符不参与拼音串拼接。

#### Scenario: 全拼命中中文历史
- **WHEN** 历史中存在"春节"且用户输入 `chun`
- **THEN** 下拉展示"春节"

#### Scenario: 首字母命中
- **WHEN** 历史中存在"春节"且用户输入 `cj`
- **THEN** 下拉展示"春节"

#### Scenario: 原文前缀优先于拼音
- **WHEN** 历史中存在"春节"与"chun城市"，用户输入 `chun`
- **THEN** "chun城市"排在"春节"之前
