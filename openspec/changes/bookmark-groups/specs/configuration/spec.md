# configuration Delta

## MODIFIED Requirements

### Requirement: 配置导入
用户必须能够从配置 JSON 文件导入并完整恢复配置；文件格式版本为 1 或 2 时均可导入，版本 1 的平铺书签列表必须自动迁移为以默认分组承载的分组结构，迁移后书签不得丢失或重复；导入非法文件（内容不是有效配置 JSON，或版本字段无法识别）时必须提示错误且保持现有配置不变。

#### Scenario: 导入恢复
- **WHEN** 用户导入此前导出的有效 JSON 文件
- **THEN** 页面立即反映文件中的书签（含分组结构）、开关、引擎与壁纸设置，并被持久化

#### Scenario: 导入 v1 文件自动迁移
- **WHEN** 用户导入版本 1（平铺书签、无分组结构）的导出文件
- **THEN** 全部书签按原顺序出现在默认分组中，分组结构与版本 2 行为一致

#### Scenario: 导入非法文件
- **WHEN** 用户导入内容不是有效配置 JSON 的文件
- **THEN** 提示导入失败，现有配置保持不变
