# configuration

## Purpose

管理导航页的个性化配置：小组件显隐开关、壁纸设置、浏览器本地持久化，以及配置的 JSON 导入导出，让用户完全掌控并迁移自己的导航页数据。

## Requirements

### Requirement: 小组件开关
用户必须能够独立开启或关闭各小组件（时钟、书签网格）的显示；开关状态立即生效并被持久保存。（假设：搜索框为导航页常驻基础组件，不提供开关。）

#### Scenario: 关闭时钟
- **WHEN** 用户关闭时钟开关
- **THEN** 时钟立即从页面消失，刷新后仍不显示

#### Scenario: 恢复显示
- **WHEN** 用户重新打开时钟开关
- **THEN** 时钟恢复显示，且相关数据与关闭前一致

### Requirement: 内置壁纸选择
系统必须提供一组内置壁纸供用户选择；选择后壁纸立即生效并被持久保存。

#### Scenario: 选择内置壁纸
- **WHEN** 用户选择某内置壁纸
- **THEN** 页面背景立即更换为该壁纸，刷新后仍保持

### Requirement: 本地上传壁纸
用户必须能够上传本地图片文件作为壁纸；上传成功后立即生效、持久保存，并在页面刷新后保持。非图片文件必须被拒绝且不影响当前壁纸。

#### Scenario: 上传并保持
- **WHEN** 用户上传本地图片成功
- **THEN** 页面背景更换为该图片，刷新后仍保持

#### Scenario: 拒绝非图片文件
- **WHEN** 用户选择的文件不是图片
- **THEN** 系统提示无效，当前壁纸保持不变

### Requirement: 本地持久化
全部用户数据（书签、搜索引擎选择、小组件开关、壁纸设置）必须保存在浏览器本地存储中，不依赖任何账号或服务端；刷新与浏览器重开后数据保持。页面加载与全部配置功能必须可离线使用。

#### Scenario: 刷新后数据保持
- **WHEN** 用户修改任意配置（书签、引擎、开关、壁纸）后刷新页面
- **THEN** 全部数据保持修改后状态

#### Scenario: 离线可用
- **WHEN** 浏览器处于离线状态
- **THEN** 页面加载与全部配置功能（查看、修改、开关、导入导出）仍可用

### Requirement: 配置导出
用户必须能够将全部配置导出为单个 JSON 文件。文件必须包含格式版本字段，并涵盖书签、小组件开关、搜索引擎选择与壁纸设置；自定义上传的壁纸必须以其图像数据内嵌，使导出文件可独立恢复完整配置。

#### Scenario: 导出产生文件
- **WHEN** 用户点击导出
- **THEN** 浏览器下载一个包含版本字段与全部配置的 JSON 文件

### Requirement: 配置导入
用户必须能够从配置 JSON 文件导入并完整恢复配置；文件格式版本为 1 或 2 时均可导入，版本 1 的平铺书签列表必须自动迁移为以默认分组承载的分组结构，迁移后书签不得丢失或重复；导入非法文件（内容不是有效配置 JSON，或版本字段无法识别）时必须提示错误且保持现有配置不变。

#### Scenario: 导入恢复
- **WHEN** 用户导入此前导出的有效 JSON 文件
- **THEN** 页面立即反映文件中的书签（含分组结构）、开关、引擎与壁纸设置，并被持久化

#### Scenario: 导入 v1 文件自动迁移
- **WHEN** 用户导入版本 1（平铺书签、无分组结构）的导出文件
- **THEN** 全部书签按原顺序出现在默认分组中，分组结构与版本 2 行为一致

#### Scenario: 导入非法文件
- **WHEN** 用户导入内容不是有效配置 JSON 的文件
- **THEN** 提示导入失败，现有配置保持不变
