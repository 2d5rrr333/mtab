# mtab 项目申报书

- **项目名称**：mtab — MoonBit 驱动的浏览器导航起始页
- **仓库链接**：https://github.com/2d5rrr333/mtab
- **许可证**：Apache-2.0（农历算法模块移植自 MIT 许可的 solarlunar，来源与修改已在 README 与源码注明）

## 项目现有基础（已全部交付）

mtab 是一个 iTab 风格的浏览器起始页，以下功能**全部已实现并通过自动化验证**：

**核心功能**
- **时钟小组件**：公历日期时间 + 农历（干支/闰月，1900–2100，移植 solarlunar 并修正干支年切换）+ 二十四节气（寿星天文历通用公式：太阳视黄经 15° 跨越判定，覆盖近似公式易错的 1987/2058 等年份）+ 传统/法定节日（含腊月廿九/三十双形态除夕判定）；节气/节日以徽章呈现（传统节日金橙、法定节日暖红、节气中性），节气徽章点击弹出科普卡片
- **书签分组**：嵌套分组模型（增删改组、固定默认分组保护、删组书签自动回落）、书签增删改、favicon 图标 + 首字回退、**指针拖拽排序**（组内换位/跨组移动/分组换序，插入指示线，与点击操作零冲突）、分组折叠状态持久记忆
- **多引擎搜索**：百度/Bing/Google 切换；**搜索历史联想**：trie 前缀检索 + 频次×7 天半衰期评分、容量 100 淘汰、↑↓/Enter/Esc 键盘导航、单条删除/一键清空；**拼音联想**：内置 ~2000 常用字无声调拼音表，英文输入可按全拼（chun→春节）与首字母（zqj→中秋节）命中中文历史，三档优先级排序
- **壁纸**：4 张内置 SVG + 本地上传（1920px 压缩）；双层层叠 crossfade（先解码后淡入，避免大图硬弹）；**模糊度调节**（0–20px 滑杆）
- **主题系统**：设计令牌化（语义色全套 CSS 变量）+ 深色/浅色/跟随系统三态，auto 实时响应系统切换
- **个性化与迁移**：小组件开关、全部配置 localStorage 持久化、离线可用；配置 JSON 导入导出，**config schema v1→v2 自动迁移**（旧导出文件导入零丢失）

**工程与质量**
- **架构**：MoonBit（wasm-gc）承担全部业务——单一 store（事件 → 新状态 + 副作用）、模型与 JSON 编解码、农历/节气天文历算、拼音表、trie、评分与淘汰；JS 渲染壳仅 ~800 行，只收集事件、重绘分区、执行副作用
- **测试**：`moon test` **122 项**（store/模型/trie/拼音/节气锚定）、Node e2e **46 项**（真实 wasm 实例过 FFI 桥）、headless Edge 双运行 **106 + 108 项**（正常 + 强制 reduced-motion，含合成 PointerEvent 拖拽全链路）
- **CI**：GitHub Actions（check/test/build/e2e + web 产物上传）；OpenSpec 规格驱动开发，**12 个 capability 需求**、11 个变更完整归档可追溯（proposal → design → tasks → 验收记录）
- **无障碍**：`prefers-reduced-motion` 全局动效关停、键盘 focus-visible 轮廓、ARIA 联想列表语义
