# mtab — MoonBit 驱动的浏览器导航起始页

## 1. 项目名称

mtab（MoonBit Tab）

## 2. 项目简介

用 MoonBit 实现的浏览器起始页（iTab 风格）：时钟（公历/农历/二十四节气/传统与法定节日）、书签分组与拖拽排序、多引擎搜索（历史联想 + 拼音联想）、壁纸与深浅色主题。全部业务逻辑——状态机、历法换算、检索与排序、配置编解码——由 MoonBit 编译为 wasm-gc 承担，HTML/CSS/JS 仅是约 800 行的渲染壳。数据全部本地存储，离线可用。

## 3. 项目方向与通用性说明

方向：应用与内容工具（Web 应用）。通用性价值有二：

- 沉淀了"**wasm 业务核心 + 薄 DOM 壳**"的完整架构样板（单一 store、事件归约、JSON 桥），可复制到任何 MoonBit 前端项目；
- 产出多个可独立复用的 MoonBit 包：字符 trie 前缀检索、无声调拼音表与查询、公历↔农历换算（1900–2100）、二十四节气天文历算。

## 4. 预期使用场景

1. **每日起始页**：打开新标签页即见时间、农历、今日节气/节日（徽章呈现，节气可点开科普卡片），选好引擎直接回车搜索。
2. **站点收藏整理**：把常用网站按"工作/学习"分组管理，拖拽调整顺序与归属，折叠不常用的分组，刷新后布局与折叠状态原样保持。
3. **中文搜索提效**：搜过"春节"后，下次只输 `chun`（全拼）或 `cj`（首字母）即可从历史联想出"春节"，无需切换输入法。
4. **数据迁移**：换浏览器或设备时导出单个 JSON 文件（自定义壁纸内嵌），新环境一键导入恢复全部配置。

## 5. 拟实现的核心功能（当前已全部实现并通过自动化测试）

- **时钟**：公历+农历（含闰月、干支）+ 24 节气（寿星天文历太阳黄经公式，1987/2058 等易错年份验证通过）+ 节日徽章与节气科普弹窗
- **书签**：分组增删改（固定默认分组、删组书签自动回落）、指针拖拽排序（组内换位/跨组移动/分组换序）、分组折叠记忆、图标获取失败回退
- **搜索**：三引擎切换；历史联想（trie 前缀检索、频次×时间衰减评分、容量 100 淘汰、↑↓/Enter/Esc 键盘导航）；拼音联想（~2000 常用字表，全拼+首字母三档优先级）
- **配置**：localStorage 持久化、离线可用、JSON 导入导出（v1→v2 结构自动迁移）、壁纸切换 crossfade 与模糊度调节、深色/浅色/跟随系统三态主题
- **质量**：moon test 122 项、e2e 46 项、headless 浏览器双运行 214 项断言、GitHub Actions CI、OpenSpec 规格驱动开发（12 条需求规格、11 个变更档案）

**原创项目**；其中公历↔农历换算模块移植自已有开源项目（见下），节气算法参考公开天文历公式，其余代码全部原创。
